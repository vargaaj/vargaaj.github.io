PyTorch + Frontier Models

Advances in Deep Learning

Covered advanced deep learning topics including memory-efficient optimization, generative models such as diffusion and auto-regressive generation, and frontier models in language and computer vision. Projects focused on implementing core model components, training pipelines, and data generation workflows in PyTorch.

Assignment 1: Low-Memory Training and Inference

Implemented memory-efficient versions of a large BigNet model while keeping outputs close to the original network and supporting automated forward and training checks.

  • Rebuilt linear layers for half-precision inference while preserving checkpoint-loading compatibility.
  • Added LoRA adapters on a frozen half-precision base so only low-rank float32 parameters were trained.
  • Implemented 4-bit block quantization, state-dict loading hooks, dequantization during forward passes, and QLoRA on top of quantized weights.

Assignment 2: Auto-Regressive Image Generation

Built a generative image pipeline for SuperTuxKart images that also served as a learned image compression workflow.

  • Implemented a patch-level autoencoder to encode and decode images through compact patch embeddings.
  • Added Binary Spherical Quantization to convert image patches into discrete token IDs.
  • Trained a causal auto-regressive model over image tokens, implemented sample generation, and prepared the optional compression path.

Assignment 3: LLM Unit Conversion

Adapted SmolLM2 to solve unit-conversion questions with direct prompting, chain-of-thought reasoning, supervised fine-tuning, and rejection-sampling fine-tuning.

  • Implemented sequential and batched text generation with tokenizer padding, attention masks, and decoded outputs.
  • Designed chat-template prompts for in-context reasoning and answer extraction.
  • Fine-tuned LoRA adapters with Hugging Face Trainer, then generated and filtered reasoning traces for RFT training data.

Assignment 4: Vision-Language Models for Tux

Fine-tuned multimodal models on SuperTuxKart image data and built a simplified CLIP-style model for visual question answering.

  • Generated expanded image, question, and answer datasets from SuperTuxKart metadata for VLM fine-tuning.
  • Created paired image-caption data for contrastive training.
  • Built a CLIP model using the VLM vision encoder and language model as encoders, then trained it for multiple-choice question answering.

NLP + Structured Prediction

Natural Language Processing

Completed a survey of modern natural language processing covering the field in two connected ways: the main academic and industry applications of NLP, plus enough linguistics to understand why those problems are challenging. The course also covered structured prediction and deep learning models including classifiers, sequence models, statistical parsers, neural network encoders, and encoder-decoder models, with attention to inference, parameter estimation, and optimization. Programming work focused on building scalable machine learning systems for practical NLP tasks.

Assignment 1: Linear Sentiment Classification

Built sparse feature-based sentiment classifiers for movie review data, using hand-engineered text features and classic online learning algorithms.

  • Implemented unigram, bigram, and cleaned bigram feature extractors with an indexed sparse representation.
  • Trained perceptron and logistic regression classifiers with stochastic updates over labeled sentiment examples.
  • Generated blind test predictions after evaluating accuracy, precision, recall, and F1 on train and development data.

Assignment 2: Neural Sentiment Classification

Rebuilt sentiment analysis with a PyTorch Deep Averaging Network over pretrained GloVe embeddings.

  • Created a trainable embedding-backed classifier with averaged word vectors, ReLU hidden layers, cross-entropy loss, and Adam optimization.
  • Added padded mini-batch training for variable-length sentences and reusable prediction wrappers for evaluation.
  • Added typo-aware inference that maps unknown words to nearby embedding-vocabulary candidates using edit distance.

Assignment 3: Transformers and Character Language Modeling

Implemented Transformer components for both sequence labeling and character-level language modeling.

  • Built a Transformer encoder with learned positional embeddings, query-key-value self-attention, residual connections, layer normalization, and feed-forward layers.
  • Trained the model on letter-counting sequence labels and emitted attention visualizations for inspection.
  • Implemented a causal Transformer language model over text8 characters with sequence log-probability scoring, normalized probability checks, and perplexity evaluation.

Assignment 4: Retrieval-Based Fact Checking

Built fact checkers that decide whether retrieved Wikipedia passages support or fail to support atomic factual claims.

  • Implemented a ROUGE-1 recall baseline that compares claim tokens against retrieved passage text.
  • Used a pretrained NLI entailment model to score passage sentences against facts and threshold support decisions.
  • Produced an error analysis report grouping mistakes into semantic similarity, implicit world knowledge, document structure, and time-period ambiguity categories.

Final Project: Adversarial Fine-Tuning for NLI Robustness

Wrote a final paper studying whether adversarial fine-tuning improves natural language inference robustness. The project fine-tuned ELECTRA-small from SNLI into progressive ANLI rounds and compared the resulting models with accuracy, confusion matrices, curated reasoning categories, and length-bias analyses.

  • Showed ANLI dev accuracy improving from 31.3% for the SNLI-only baseline to 40.6% after r1+r2+r3 adversarial fine-tuning.
  • Found that SNLI dev accuracy stayed nearly unchanged, with the extra SNLI plus ANLI model retaining 89.6% versus 89.7% for the SNLI-only baseline.
  • Analyzed how adversarial training reduced neutral-label collapse and mitigated length-based shortcut behavior while preserving in-domain performance.

Kernel + Systems

Advanced Operating Systems

Studied the formal structure, design principles, organization, implementation, and performance analysis of multiprogramming and multiprocessor computer systems. The course centered on three operating systems themes: virtualizing the CPU, virtualizing memory, and virtualizing storage, with lectures based on textbook chapters and selected research papers.

Project 0A: Wish Shell

Built a small Unix-like shell to understand how command-line interfaces coordinate processes, paths, input modes, and command execution.

  • Implemented command parsing and execution flow for interactive and batch workflows.
  • Added shell-level behavior for navigation, executable search paths, output redirection, and running multiple commands from one input line.
  • Focused on robust error handling and process management in a C/Linux environment.

Project 0B: Intro to Pintos

Used a focused Pintos warm-up to learn how the kernel codebase represents threads and shared data structures.

  • Explored the Pintos build and test workflow, documentation, and project submission process.
  • Worked with kernel list abstractions and thread metadata.
  • Produced a small patch against the OS codebase while preserving the original source for comparison.

Project 1: Threads

Extended Pintos threading to make the scheduler and synchronization primitives behave more like a real kernel.

  • Replaced inefficient sleep behavior with blocking and wakeup logic driven by timer interrupts.
  • Added priority-aware scheduling across ready queues and synchronization waiters.
  • Implemented priority donation to reduce priority inversion in lock-heavy workloads.
  • Balanced correctness with minimal interrupt disabling and no busy waiting.

Project 2: User Programs

Built the boundary between user programs and the Pintos kernel so user code could run safely and interact with OS services.

  • Added process startup support, argument passing, and parent-child lifecycle coordination.
  • Implemented a system-call layer for process control and file operations.
  • Managed per-process resources such as file descriptors and executable state.
  • Hardened the kernel against invalid user memory and concurrent file system access.

Project 3: Virtual Memory

Added demand-paged virtual memory so Pintos could load, evict, and restore user pages as needed.

  • Designed data structures to track virtual pages, physical frames, and swap space.
  • Loaded executable and stack pages lazily on page faults.
  • Added page replacement, eviction, swap-backed recovery, stack growth, and cleanup on process exit.
  • Coordinated VM behavior with kernel I/O so user buffers remained safe while devices accessed them.

Project 4: File Systems

Expanded the Pintos storage layer into a more complete file system with growth, hierarchy, persistence, and concurrency.

  • Reworked file layout to support growing and sparse files without relying on contiguous disk extents.
  • Added hierarchical directories, path traversal, and per-process working directories.
  • Extended file-system behavior to support directory operations and metadata queries.
  • Improved synchronization so independent file and directory activity could proceed safely in parallel.
